# Privacy Policy — BetterCompare MCP Proxy

Last updated: April 30, 2026

## Data Collection
This proxy does not collect, store, or share personal user data.

## Tool Calls
Tool calls are processed in memory only and are not persisted to any database.

## Logs
Request traces are stored in memory for debugging purposes only and are reset on each deployment.
